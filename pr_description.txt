Root cause: Agent sessions started at the drive root left temporary files and caches because the session working directory was inherited without any `PRIME_AGENT_SESSION_TMP` overrides for `TMP`, `TEMP`, or `TMPDIR`.
Fix: Injected a `tmp` folder created inside the session artifact directory into `_rlmKernelEnv()` and allowed `executeBash` to merge this environment when executing `bash` tools.
Validation: Wrote a regression test `packages/coding-agent/test/suite/regressions/1936-session-tmp.test.ts` to execute a bash and Python command inside a session reading the respective variables. Verified using `npx tsx ../../node_modules/vitest/dist/cli.js --run test/suite/regressions/1936-session-tmp.test.ts`. Also validated with `npm run check`.
